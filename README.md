# 风起簿 · Windveil Journal

> 等风来，再启程。

**风起簿**是一款 Android 原生的个人愿望陪伴应用。它收集那些你不想错过的未来——想一个人去看海、想重新开始画画、想在父母还健康时多去旅行——并在时机合适时，陪你慢慢发生。

**它不是待办清单。** 没有逾期、没有完成率、没有连续打卡。写在这里的事不急，这里替你记着，等风来。

## ✨ 为什么用风起簿

- **零账号、纯本地**：不需要注册登录，所有数据只存在你的手机里（Room 本地库），没有服务器、没有上传。换手机用「导出/导入 JSON」迁移。
- **不制造焦虑**：没有红字逾期、没有打卡压力。愿望的状态是「刚种下 → 正在酝酿 → 风来了 → 正在发生 → 已经发生 / 安静放下」——每一态都是温柔的描述，不是失败的记录。
- **提醒交给系统日历**：约定的时机写入你的系统日历（需要你确认），到点由系统提醒，不依赖应用在后台活着，也不怕杀后台。
- **AI 陪伴但不越界**：接你自己的大模型（DeepSeek 等任何 OpenAI 兼容接口），聊天、理解愿望、拆解步骤、给时机建议；模型不可用时照常记录，绝不因 AI 失败丢你的话。数据只发往你自己配置的模型端点。

## 🌟 核心功能

### 未发生之地（愿望）
- **一句话种下**：不用想步骤和日期，写下原话即可。
- **AI 静默理解**：自动提炼你的感受和第一小步，还会温柔地问你一句（可跳过）。
- **约定时机**：让 AI 提个时候，或自己选——法定节假日（下拉）、具体年月日（年/月/日三个下拉）。到点自动写入系统日历提醒。
- **随时调整**：还不是现在（顺延）、安静放下、重新种下，随时改。

### 心语（AI 聊天）
- **说想法，它记录**：「我想去吃自助」→ 自动记下；未来愿望进未发生之地，当下小事进随手记。
- **问建议，它翻记忆**：「明天中午吃什么」→ 它检索你的记录给建议；你说在减肥、又想吃自助，它会温和地把自助排在后面。
- **越用越懂你**：自动从对话中提炼你的偏好（有空时间、运动、饮食……），形成用户画像，建议越来越贴合；画像条目可随时查看、删除。

### 随手记
- 一句话记下不值得变成愿望的念头（今晚吃什么、周末取快递）。
- 支持补充**文字备注和照片**（观后感、聚会照片）。
- 划掉后自动收进「已发生之书」的随手记部分，留下的都是生活过的痕迹。

### 已发生之书
- 愿望实现后写一页记忆：起因、经过、心情、最后一行。
- 分「愿望 | 随手记」两部分，沉淀你活过的每一页。

## 📖 使用指南

1. **安装后直接用**：无注册、无登录，打开就是「未发生之地」。
2. **配置 AI（可选但推荐）**：「我的 → 心语与模型」填入模型接口地址、API Key、模型名（如 DeepSeek：`https://api.deepseek.com`）。不配置也能正常记录，只是没有 AI 理解和建议。
3. **开启日历提醒（推荐）**：「我的 → 提醒（系统日历）」授权日历权限，约定时机后自动写入系统日历。
4. **日常使用**：
   - 想到一件未来想做的事 → 未发生之地 → 种下一个
   - 随手的念头 → 随手记 Tab 一句话记下
   - 对话倾诉或找建议 → 心语
5. **数据备份**：「我的 → 数据」导出 JSON；新手机上用「导入」恢复。

## 🛠 技术栈

| 维度 | 选择 |

## 📂 项目结构

```text
android/                      App 源码（项目主体）
  app/src/main/java/com/windveil/journal/
    data/local/db/            Room：愿望、随手记、记忆页、用户画像
    data/local/               模型配置（LLM ConfigStore）
    data/remote/              心语直连模型客户端
    data/repository/          StandaloneRepository（业务规则收口）
    domain/                   时机计算、节假日数据、日历提醒、AI 分析、导出
    presentation/             主题、导航与全部页面
  app/src/main/assets/        法定节假日数据（按年份）
  app/src/test/               单元测试（时机计算、契约、API 行为）
.three-tomato/requirements/   产品 PRD 与 API 契约（需求参考存档）
release/                      预构建 APK 下载
```

## 🔨 从源码构建

1. 用 Android Studio（Hedgehog 以上）打开 `android/` 目录，等待 Gradle Sync。
2. 直接运行 `app` 到设备/模拟器。
3. 单元测试：

   ```bash
   cd android
   ./gradlew :app:testDebugUnitTest
   ```

## 📝 设计原则

1. 不制造焦虑，不强调连续打卡。
2. 不滥用提醒，只有值得出现时才出现。
3. 不替用户定义「应该做什么」。
4. 接受愿望被修改、暂停，甚至被放下。
5. 将「完成」理解为经历，而不是勾选。
