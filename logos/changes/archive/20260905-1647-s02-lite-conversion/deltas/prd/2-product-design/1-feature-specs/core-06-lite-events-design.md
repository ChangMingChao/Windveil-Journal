# delta — core-06-lite-events-design.md（s02-lite-conversion）

## ADDED — S09 增补：来自 S02 转换的轻事件

> 追加到本文件交互规格之后。S02 的 near_term_todo 询问（EX-18.2）新增第三选项「先记一下」后，轻事件可能来自转换而非直接输入。

**来源标注**

| 元素 | 规格 |
|------|------|
| 转换来源的轻事件 | 与直接输入的轻事件**完全相同**地展示（同列表、同划掉/收走），不加来源徽标——用户不关心它是怎么来的 |
| 转换文案 | 转换成功后 P1 询问卡显示「已经先帮你记下来了」；轻事件列表随即包含该条 |

**明确不存在的元素**：来源徽标（「来自愿望」）、原 wish_id 的任何残留引用、转换后的确认弹层。

### 验收条件（交互级）

##### 正常：转换后轻事件立即可见可划掉
- **GIVEN** 用户在 S02 询问卡选择了「先记一下」
- **WHEN** 转换完成
- **THEN** P1 的轻事件列表包含该文本；用户可正常划掉或收走；询问卡关闭并显示「已经先帮你记下来了」
