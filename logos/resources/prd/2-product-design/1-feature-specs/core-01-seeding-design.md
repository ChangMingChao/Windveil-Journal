## S01: 新用户建立自己的未发生之地 — 交互规格

**涉及页面**：`/welcome` 首次体验流（W1 欢迎 → W2 温柔问题 ×3 → W3 第一次种下 → W4 Agent 轻问）→ `/garden`

**页面元素**

| 页面 | 元素 | 规格 |
|------|------|------|
| W1 欢迎 | 一句欢迎语、一盏渐亮的灯（SVG）、「开始」按钮 | 灯的渐亮动效 600ms，`prefers-reduced-motion` 时直接呈现终态 |
| W2 温柔问题 | 问题文案、多行输入框、「继续」、「先直接写一个愿望」（顶部文字按钮）、进度指示（3 个纸点，非进度条） | 共 3 题，每题均可留空继续；纸点仅表示位置，不显示百分比 |
| W3 第一次种下 | 「今天，有什么想在未来发生的事吗？」、输入框、语音按钮、「种下」按钮 | 输入为空时「种下」按钮禁用（`disabled` + `aria-disabled`），不弹校验提示 |
| W4 Agent 轻问 | 生成的愿望卡预览、Agent 一句追问、「回答」输入框、「先不说」 | 追问最多 1 句；两个动作均直接进入 `/garden` |

**交互流程**

1. 新用户打开 `/` → 检测无个人空间 → 重定向 `/welcome`（W1）
2. 点「开始」→ W2 第 1 题；每题「继续」推进，答案实时暂存到本地草稿
3. 任意题点顶部「先直接写一个愿望」→ 跳过全部剩余问题 → 直接 W3；已答内容保留提交
4. W3 提交（文字或语音）→ 按钮进入 loading 态（禁用 + 纸片旋转指示）→ Agent 理解
5. 理解成功 → W4 展示愿望卡 + 1 句追问；理解失败 → 跳过 W4，直接进入 `/garden` 并展示降级卡片与提示条
6. 进入 `/garden`，底部导航首次出现，`/welcome` 从此不可再进入（`localStorage.onboarded = true` + 服务端标记）

### 验收条件（交互级）

##### 正常：完整走完温柔问题并种下第一个愿望
- **GIVEN** 新用户位于 `/welcome` 的 W1，`localStorage.onboarded` 不存在
- **WHEN** 用户点「开始」，在 W2 三题分别输入内容并各点一次「继续」，在 W3 输入框键入「等压力没这么大的时候，想去海边待两天」（此时「种下」按钮由 `disabled` 变为可点），点击「种下」
- **THEN** 「种下」按钮进入 loading 态并禁用，≤5 秒内进入 W4；W4 卡片显示标题「去海边待两天」、`种下于 2026 年 9 月`、原话引用、状态徽标「刚种下」（雾蓝圆点 + 文字 + 种子形状），下方为 1 句追问与「回答」／「先不说」；点任一动作后进入 `/garden` 并展示该卡片，底部导航出现

##### 正常：跳过温柔问题直接种下
- **GIVEN** 用户位于 W2 第 1 题，已在输入框填写了部分内容
- **WHEN** 用户点击顶部「先直接写一个愿望」
- **THEN** 页面直接切到 W3（跳过第 2、3 题），第 1 题已填内容随本次记录一并提交；W3 及后续页面不出现「还有 2 个问题未回答」类提示、不出现红点、不出现返回补答入口

##### 异常：跳过后未输入任何内容即离开
- **GIVEN** 用户位于 W3，输入框为空，「种下」按钮为 `disabled`
- **WHEN** 用户点击左上返回或直接关闭标签页后重新打开 `/`
- **THEN** 个人空间已建立，直接进入 `/garden`（不再回到 `/welcome`）；`/garden` 显示空状态「这里还什么都没有。想到什么，随时来种下它。」+ 居中「种下」入口；页面无进度条、无「完成设置」提示

##### 异常：Agent 理解服务不可用
- **GIVEN** 用户在 W3 已输入一句愿望，Agent 理解接口将超时（>5 秒）或返回 5xx
- **WHEN** 用户点击「种下」
- **THEN** loading 态最多持续 5 秒后结束，跳过 W4 直接进入 `/garden`；新卡片标题为原话前 20 字、状态「刚种下」、原话完整保留；页面顶部出现一条可关闭的纸色提示条「先替你收好了，我稍后再慢慢读它」；界面不出现错误码、不出现「重试」按钮

## S02: 随手种下一个愿望并被理解 — 交互规格

**涉及页面**：`/`（P1 种下一个愿望）→ Agent 轻问半屏 → `/garden`

**页面元素**

| 区域 | 元素 | 规格 |
|------|------|------|
| 顶部 | 一行时间感文案（如「2026 年 9 月的一个傍晚」） | 纯装饰，`ink-soft`，13px |
| 输入区 | 提示语「今天，有什么想在未来发生的事吗？」+ 自动增高输入框（上限 500 字） | 16px 正文；聚焦时描边由 `line` 变 `clay`，无位移 |
| 工具行 | 语音按钮（长按录音）、照片按钮、字数提示（仅在 >450 字时出现） | 按钮 44×44px，均有 `aria-label` |
| 主动作 | 「种下」按钮（`clay` 底 + 白字，对比 7.09:1） | 空内容时 `disabled`；提交中 loading |
| 轻问半屏 | 愿望卡预览 + 1 句追问 + 「回答」输入框 + 「先不说」 | 由底部升起 240ms；可下滑关闭，等同「先不说」 |

**交互流程**

1. 用户从任意页面点底部居中「种下」→ 进入 `/`
2. 输入文字，或长按语音按钮说话（≤60 秒，实时显示波形与剩余秒数，松手即提交）
3. 可选：附加照片（≤9 张）
4. 点「种下」→ Agent 在 5 秒内返回结构化理解（感受倾向 / 隐含条件 / 最小下一步）
5. 轻问半屏升起 → 用户回答或「先不说」
6. 进入 `/garden`，新卡片以「发芽」动效插入花园顶部（600ms，reduced-motion 时直接出现）

### 验收条件（交互级）

##### 正常：一句话文字输入生成愿望卡
- **GIVEN** 已完成首次体验的用户位于 `/`，输入框为空且「种下」按钮为 `disabled`
- **WHEN** 用户键入「想在冬天学会滑雪」，点击「种下」
- **THEN** 按钮进入 loading 并禁用，≤5 秒内轻问半屏由底部升起；卡片预览含标题「学会滑雪」、`种下于 2026 年 9 月`、原话引用、状态徽标「刚种下」；Agent 追问恰好 1 句（如「想在哪座山？还是还没想到？」）；详情页数据中隐含条件包含「季节：冬季」，且已生成 1 条最小下一步（此时不展示）

##### 正常：语音输入并跳过追问
- **GIVEN** 用户位于 `/`，浏览器麦克风权限为 granted
- **WHEN** 用户长按语音按钮说话 18 秒后松手，随后在轻问半屏点击「先不说」
- **THEN** 录音期间显示波形与剩余秒数（60 秒上限倒数）；松手即进入转写与理解；轻问半屏中的问题被标记为「待未来再问」但当次不再出现；页面进入 `/garden`，新卡片以发芽动效插入顶部；原始音频在详情页可回放

##### 异常：输入内容是当下的日程而非未来的愿望
- **GIVEN** 用户位于 `/`
- **WHEN** 用户键入「今天下午 3 点开会」并点击「种下」
- **THEN** 内容已落库不丢失；轻问半屏以询问语气确认「这更像是这几天要办的事，还是你想在未来发生的事？」，提供两个动作：「就当成一件未来的事」（保留为愿望卡）与「删掉它」（删除该条并返回 `/`）；界面不出现「格式错误」「请输入有效内容」一类纠正性文案

##### 异常：语音权限被拒绝或转写失败
- **GIVEN** 用户位于 `/` 并尝试语音输入
- **WHEN** 麦克风权限被浏览器拒绝
- **THEN** 出现一次授权引导（说明为何需要麦克风 + 「去设置」+ 「用文字写」），输入框内已有文字不被清空；用户选「用文字写」后引导消失且本次会话不再弹出
- **WHEN** 权限正常但转写接口返回失败
- **THEN** 仍生成愿望卡，标题为「一段还没被读懂的话」，状态「刚种下」，原始音频完整保留；详情页提供「再读一次这段话」（重试转写）与「我自己写下来」（手动补文字）两个入口；不丢失录音、不阻塞进入 `/garden`

## ADDED — S09 增补：P1「先记一下」区 — 交互规格

> 追加到本文件的 S02 交互规格之后。完整 S09 规格见 `core-06-lite-events-design.md`；此处只定义 P1 页面上的入口与列表区。

**P1 页面新增区域（主输入下方）**

| 元素 | 规格 |
|------|------|
| 「先记一下」次级入口 | 文字链接样式（非按钮，不与主输入的「种下」竞争），固定在主输入区下方；点击展开单行输入 + 「记下」按钮 |
| 轻事件列表 | 「先记一下」展开时显示现有轻事件（最近在上，最多渲染 8 条，无「查看全部」——轻事件没有翻页价值）；每条一行：内容 + 「划掉了」+「收走」 |
| 「划掉了」 | 该行状态转 done，从列表消失（240ms 淡出）；无确认步骤（轻事件不值得二次确认） |
| 「收走」 | 硬删除该行；与「划掉了」并列但不突出 |
| 空列表 | 展开时无任何轻事件 → 只显示输入框 + 一句引导「想到什么小事，一句话记下它」 |

**明确不存在的元素**（验收要检查其缺失）：轻事件条数、完成/未完成计数、时间戳展示、任何提醒开关、把轻事件「升格为愿望」的按钮。

**交互流程**

1. 用户点「先记一下」→ 展开输入与列表（再次点击收起，列表随之隐藏）
2. 输入一句话（≤200 字）→ 「记下」→ 轻事件置顶出现在列表（输入框清空，可连续记）
3. 「划掉了」→ 该行淡出消失
4. 「收走」→ 该行立即消失（无确认，轻事件不值得打断用户）

### 验收条件（交互级）

##### 正常：连续记两条并划掉一条
- **GIVEN** P1 页「先记一下」已展开，列表为空
- **WHEN** 用户输入「今晚吃火锅」记下，再输入「周末取快递」记下，随后把「今晚吃火锅」划掉
- **THEN** 两条按时间倒序出现在列表（最近的在上）；划掉后列表只剩「周末取快递」；输入框在每次记下后清空且可立即输入下一条；全程页面无任何数字变化

##### 异常：空内容禁用保存
- **GIVEN** 输入框为空或仅空白
- **WHEN** 用户查看「记下」按钮
- **THEN** 按钮禁用；服务端同样拒绝空内容（422），两层防御
