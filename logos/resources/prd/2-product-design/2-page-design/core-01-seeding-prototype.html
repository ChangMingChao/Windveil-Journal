原型 · 种下一个愿望

场景 S01（新用户建立自己的未发生之地）与 S02（随手种下一个愿望并被理解）。视口 375px。 设计令牌来自 design-system.json。可交互：切换屏幕、跳过温柔问题、输入后启用「种下」、 提交后的 loading 与 Agent 轻问。

这一屏在验收什么

  • W2 顶部「先直接写一个愿望」可在任意题跳过，跳过后不再出现补答提示或红点。
  • W3 空输入时「种下」为 disabled + aria-disabled，不弹校验。
  • 提交进入 loading 且按钮禁用，≤5 秒内出结果（原型模拟 1.2 秒）。
  • W4 追问恰好 1 句，两个动作都直达花园。
  • 状态徽标 = 圆点 + 文字 + 形状描述，颜色不作唯一指示。
  • 装饰色 #8FA5B0 / #E8B96B / #6B7B3C 实测对比度低于 4.5:1， 原型中只用于圆点与光晕，文本一律使用 #2C2620 / #5C5347 / #92400E / #4A6572 / #4F5C2C。
  • 全部图标为内联 SVG（24×24），无 emoji；可点击元素 ≥44×44px。
  • prefers-reduced-motion: reduce 下动效全部关闭。

对应验收条件见 ../1-feature-specs/core-01-seeding-design.md。
